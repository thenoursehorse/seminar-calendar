UQ Seminar Calendar

Subscribe to UQ School of Mathematics and Physics seminar calendars in your calendar app.

Available Calendars

  • Physics Colloquium
    https://thenoursehorse.github.io/seminar-calendar/physics-colloquium.ics

How to Subscribe

Google Calendar

  1. Open Google Calendar → Settings → "Other calendars" → "From URL".
  2. Paste the .ics URL above.
  3. Click "Add calendar".

Apple Calendar

  1. File → New Calendar Subscription.
  2. Paste the .ics URL.
  3. Set refresh frequency (e.g. "Every day").

Outlook

  1. Add calendar → "From Internet" / "Subscribe from web".
  2. Paste the .ics URL.

Notes

  • Google Calendar refreshes subscribed calendars approximately every 12–24 hours.
  • Events older than one year are automatically removed from the calendar feed.
  • Calendars are updated daily at 1pm AEST. In the worst case, it could take up to ~35 hours for a website change to appear in your calendar (next CI run + CDN cache + client refresh).
  • For same-day cancellations, check the UQ website directly.
